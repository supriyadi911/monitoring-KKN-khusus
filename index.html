          Optimasi Koneksi Database

          Agar koneksi dari perangkat Anda ke database aplikasi SIM KKN lancar, silakan atur DNS Pribadi (Private DNS) di HP Anda:

          1. Buka Pengaturan (Settings) HP.
          2. Cari menu Koneksi / Jaringan.
          3. Cari pengaturan DNS Pribadi (Private DNS).
          4. Pilih "Host penyedia DNS Pribadi" dan ketik:
            dns.google.com
          5. Simpan pengaturan.
